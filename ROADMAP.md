# Roadmap

## Before public launch

- Confirm production domain and add canonical URLs to every page
- Confirm the intended production domain and canonical URLs
- Re-capture the Etsy inventory immediately before public launch so prices and availability are current
- Add a dedicated maker portrait later if desired; the About page currently uses real workshop photography

- Add automated Etsy catalog synchronization if a reliable approved data source is available
- Add a third-party form endpoint if email-app submission proves inconvenient
- Add individual editorial collection landing pages when enough verified products exist
- Add structured Product data only for verified, current listing data
- Add automated accessibility and broken-link checks in continuous integration
